# 직접 측정: 반복 입력이 얼마나 줄었는가

## 아직 없는 증거

OCR 처리시간과 실제 업무시간은 다르다. 현재 수작업·검토 소요시간은 미측정이다. 아래 6회 작업만 사용자가 직접 수행하면 첫 비교 기록을 만들 수 있다. 실제 ecom에 접속하지 못하면 결과 이름은 "엑셀 초안 작성 비교"로 유지한다.

## 같은 종료 조건

양쪽 모두 공통 16개·품목 12열을 채우고 원문 대조를 마친 시점까지 잰다. 동일한 가상 기본 설정 4개를 시작 전에 양쪽에 제공한다. 모르는 원산지코드는 같은 이유로 공란 유지하며 신고 완료로 표시하지 않는다. 정답 JSON은 작업이 끝난 다음 대조한다.

- **수작업:** PDF를 열고 빈 Excel의 공통 16개·품목 12열에 작성한다. 기존에 쓰던 OCR 복사 등을 허용했다면 그 도구를 기록하고 양쪽 기준을 바꾸지 않는다.
- **도구 사용:** `/preparation`에서 해당 PDF를 선택한다. 사례 정답의 profile 4개만 미리 설정한다. PDF 처리 시작 → 전체 값과 원문 대조 → 누락 행·값 보완 → JSON 저장까지 잰다. 매핑 개선에 사용한 세 번째 문서도 제외하지 않는다.
- 공통 총중량·전체순중량과 품목별 순중량을 혼동하지 않는다. 품목 순중량은 모두 공란이다.

첫 문서는 수작업부터, 두 번째는 도구부터, 세 번째는 수작업부터 진행한다. 같은 문서를 두 번 보므로 기억 효과가 생긴다. 이는 탐색적 개인 측정이며 엄밀한 현업 효과 검증은 아니다. 설명 듣기·실행 환경 설치 시간은 별도 기록한다. 중단이 생기면 이유와 중단 시간을 남긴다.

| 사례 | 순서 | 수작업 총 초 | 도구 사용 총 초 | 직접 수정·추가한 칸 | 최종 오답·누락 칸 | 사용 도구·중단 메모 |
|---|---|---:|---:|---:|---:|---|
| DEMO-001 | 수작업 → 도구 | 미측정 | 미측정 | 미측정 | 미측정 | |
| DEMO-002 | 도구 → 수작업 | 미측정 | 미측정 | 미측정 | 미측정 | |
| DEMO-003 | 수작업 → 도구 | 미측정 | 미측정 | 미측정 | 미측정 | |

절감률은 `(수작업 총 초 - 도구 사용 총 초) / 수작업 총 초 × 100`으로 계산한다. 느려졌다면 음수 그대로 남긴다. 도구 결과가 더 틀렸거나 검토를 덜 했다면 시간만으로 효과를 주장하지 않는다. 결과는 "합성 문서 3건, 본인 1명, 엑셀 초안 작성 비교"라고 표현한다.

측정값을 전달하면 면접 문구에 사실대로 반영할 수 있다. 값을 모르면 빈칸으로 두며 예시 숫자를 채우지 않는다.
